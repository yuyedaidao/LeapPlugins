# 关机

在 Leap 里立即关机或定时关机，并取消定时关机。macOS 专用。

## 用法

输入时长后按 Enter，或直接用方向键选择列表项：

| 输入 | 效果 |
| --- | --- |
| 留空，选「立即关机」 | 立即关掉这台 Mac |
| `30`、`30分钟`、`30m` | 30 分钟后关机 |
| `2小时`、`2h` | 2 小时后关机 |
| `1.5h`、`90分钟` | 90 分钟后关机 |
| `0` | 立即关机 |
| `取消`、`cancel`、`off` | 取消当前的定时关机 |

取消成功后 Leap 会收起并发一条通知「已取消定时关机（原定 18:30）」；本来就没有定时任务时只提示「当前没有定时关机任务」，不收起窗口。

不带单位的数字按分钟计算。定时任务最多 7 天；小数时长四舍五入到分钟，不足 1 分钟按立即关机处理。

安排成功后系统会发一条通知，弹窗提示具体时间，选中列表项后收起 Leap。再次安排会自动替换旧的定时任务，不会重复排队。

## 关机方式

通过 AppleScript 通知系统关机，等价于菜单栏「关机」：

```text
osascript -e 'tell application "System Events" to shut down'
```

不需要管理员密码，但会请求「自动化」权限，允许 Leap 控制 System Events 后才能生效。首次安排时会提前触发一次无害的读取来弹出授权，避免到点才发现没有权限；日志里留有失败原因。

系统关机前的行为与手动关机一致：未保存的文档可能丢失，后台任务会被中断。请在到点前保存工作。

## 定时实现与取消

定时任务是一个脱离 Leap 的后台进程，Leap 退出或收起窗口都不影响它：

- 用 `/bin/zsh -l -c` 启动，按绝对时间轮询（每 10 秒检查一次），系统休眠不会让关机时间顺延到最后一次醒着的时间。
- 任务信息写入 `~/Library/Application Support/Leap/PluginData/com.padding.leap.shutdown/state.json`，包含进程 PID、关机时间和一个唯一标识。
- 取消时先确认该 PID 的命令行里仍带着这个唯一标识，再终止整个进程组，避免 PID 被复用后误杀其它进程；随后删除记录，收起 Leap 并发送通知。与「立即关机」「定时安排」一样，动作生效后窗口就收起，不留可重复按的旧列表项（宿主没有从选中回调刷新列表的接口）。

可以直接在 Finder 或「活动监视器」里删除该进程，效果等同于取消，但插件不会自动知道记录已失效，选择「取消」时会顺带清理。

## 日志

每次启动关机任务写一个日志：

```text
~/Library/Logs/Leap/shutdown/<时间>-<唯一标识>.log
```

记录了实际执行的脚本和 `osascript` 的报错。日志不自动清理。

## 安装

最低要求 Leap 0.0.2（清单里的 `minimumHostVersion` 高于本机版本时会提示「插件要求的 Leap 版本无效或高于当前版本」）。在 Leap「设置 → 插件 → 安装插件 → 从本地目录安装」中选择整个 `shutdown` 目录，或通过「从远程地址安装」使用目录链接。无需额外运行时或第三方依赖。

## 图标生成记录

`icon.png` 使用本地 PIL 脚本绘制（1254×1254，与仓库内其它插件一致）：深蓝灰底色，居中的暖橙色电源符号——上方短竖条与下方开口圆环，笔画粗、留白大，24 与 32 像素下仍可辨认。
